# Лаборатори №7 — Exploratory Testing (SBTM)

## Оюутны мэдээлэл
- **Оюутны нэр:** `А.Төгөлдөр`
- **Оюутны код:** `B242270001`
- **Хичээл:** F.CSA313 — Программ хангамжийн чанарын баталгаа ба тест
- **Node.js:** `v24.19.0`
- **Үйлдлийн систем:** Ubuntu Linux
- **Браузер:** Google Chrome
- **Тестлэх апп:** Уншлагын жагсаалт, `http://localhost:3000`

## Тестийн тойм
«Уншлагын жагсаалт» аппын ном нэмэх, хайх, устгах, тоолуур, хүснэгтийн дүрслэл, навигац болон API-ийн алдаатай оролтод үзүүлэх хариуг хар хайрцгийн аргаар шалгав. Багшийн өгсөн спецификацийг зөв зан төлөвийн oracle болгон ашиглав.

## Хэсэг E — Дүгнэлт (Debrief)
Энэхүү exploratory тестийн session-ий хүрээнд Couch Potato, Fed-Ex, Supermodel болон Saboteur аяллуудыг системтэй ашиглаж нийт 10 согог илрүүллээ. Couch Potato аяллаар талбарын хоосон болон хязгаараас гадуурх утгуудыг туршихад BUG-01 болон BUG-08 илэрсэн. Fed-Ex аяллаар өгөгдлийн урсгалыг шалгах явцад ижил өгөгдөл давхардах (BUG-02) болон тоолуурын зөрүүтэй байдал (BUG-06) ажиглагдав. Supermodel аяллаар GUI-г шалгаснаар оны формат (BUG-03), товчны өнгө (BUG-04), урт текстын эвдрэл (BUG-05), хуучин хувилбарын холбоос (BUG-07) болон хайлтын том/жижиг үсгийн ялгаа (BUG-09) илэрсэн. Saboteur аяллаар API руу буруу JSON биет илгээхэд сервер `200 OK` буцаах согог (BUG-10) илэрлээ. Илэрсэн согогуудаас талбарын баталгаажуулалт, давхардал, тоолуур, оны хүрээ болон API-ийн статус кодыг Playwright автомат тестээр хялбархан барьж авах боломжтой. Харин устгах товчны өнгөний тохиромж, урт текстээс үүдэлтэй хүснэгтийн макетын эвдрэл зэрэг дизайн болон харагдацын асуудлуудыг хүний санал шаардлагатай интерфэйсийн ажиглалтаар илрүүлэхэд хамгийн тохиромжтой байв. Дараагийн session-д тусгай тэмдэгтүүд бүхий оролтууд, сүлжээний сааталтай үеийн аппын төлөв болон хэд хэдэн үйлдэл дарааллан хийх үеийн санах ойн төлөвийг гүнзгийрүүлэн шалгах шаардлагатай байна.
