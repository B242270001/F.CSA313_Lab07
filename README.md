## Хэсэг E — Дүгнэлт (Debrief)
Энэ session-д Couch Potato болон Saboteur аяллууд хамгийн үр дүнтэй байв. Couch Potato аяллаар заавал бөглөх талбарууд, онгийн хүрээ ба бүхэл тооны баталгаажуулалт зэрэг энгийн хэрэглэгчийн үйлдэлтэй холбоотой согогууд илэрсэн. Өгөгдлийн замыг шалгах үед ижил гарчиг, зохиолчтой номыг давхар нэмэх боломжтой байгааг ажигласан. Saboteur аяллаар буруу JSON биет илгээхэд сервер 400 Bad Request бус 201 Created буцааж байгааг `curl -i` гаралтаар баримтжуулсан. GUI-г ажиглах явцад оны формат, устгах товчны өнгө, урт гарчиг хүснэгтэд нөлөөлөх байдал илэрсэн. Charter-аас гадуур хайлтын том/жижиг үсгийн ялгаа болон «Хуучин хувилбар» холбоосын алдааг мөн шалгасан. Playwright автомат тестээр талбарын баталгаажуулалт, давхардал, онгийн хүрээ, хайлт, тоолуур болон API статус кодыг шалгаж болох байсан. Товчны өнгө, хүснэгтийн эвдрэл, мессежийн ойлгомжтой байдал зэрэг харагдах байдлын асуудлыг автомат тестээр шалгаж болох ч хүний нүдээр давхар үнэлэх нь хэрэгтэй. Дараагийн session-д хязгаарын утгууд, хоосон зайтай оролт, урт зохиолчийн нэр, устгасны дараах тоолуур болон бусад холбоосын бүх чиглэлийг системтэй шалгана.
