# BUG-02: Ижил гарчиг, зохиолчтой номыг давхар нэмж болдог

**Орчин:** Уншлагын жагсаалт v2.0, Google Chrome, Ubuntu Linux, 2026-10-17

**Урьдчилсан нөхцөл:** Аппыг шинээр асаасан, анхны 3 ном жагсаалтад байна.

## Дахин гаргах алхам

1. `http://localhost:3000` хаягаар аппыг нээнэ.
2. Жагсаалтад байгаа номын гарчиг, зохиолч, оны утгыг тэмдэглэнэ.
3. Ном нэмэх хэсэгт ижил гарчиг, ижил зохиолч оруулна.
4. Оны утгыг хүчинтэй бүхэл тоогоор бөглөнө.
5. **Нэмэх** товчийг дарна.
6. Ижил гарчиг, зохиолчтой ном дахин нэмэгдсэн эсэхийг шалгана.

## Хүлээгдэж байсан үр дүн

Ижил гарчиг, зохиолчтой ном давхар нэмэгдэхгүй байх ёстой. Давхардсан тохиолдолд ном нэмэхгүй бөгөөд тохирох мэдэгдэл харуулна.

## Бодит үр дүн

Ижил гарчиг, зохиолчтой номыг дахин нэмэх боломжтой байсан.

**Ноцтой байдал:** Major — номын жагсаалтад давхардсан өгөгдөл үүсгэнэ.
