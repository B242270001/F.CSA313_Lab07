# BUG-06: “Хуучин хувилбар” холбоос Internal Server Error алдаа гаргадаг

**Орчин:** Уншлагын жагсаалт v2.0, Google Chrome, Ubuntu Linux, 2026-10-16

**Урьдчилсан нөхцөл:** Аппыг шинээр асаасан, үндсэн нүүр хуудас амжилттай нээгдсэн байна.

## Дахин гаргах алхам

1. `http://localhost:3000` хаягаар аппыг нээнэ.
2. Хуудасны доод хэсэгт байрлах **Хуучин хувилбар** холбоосыг олно.
3. Холбоос дээр дарна.
4. Нээгдсэн хуудасны үр дүнг шалгана.

## Хүлээгдэж байсан үр дүн

Холбоос ажиллаж, зориулалтын хуучин хувилбарын хуудас эсвэл тохирох хувилбар руу шилжүүлэх ёстой.

## Бодит үр дүн

`Internal Server Error` гэсэн алдааны хуудас гарсан.

**Ноцтой байдал:** Major — холбоосын зориулалттай хуудас ашиглах боломжгүй байна.
