# BUG-08: Буруу JSON биеттэй POST хүсэлтэд 400 биш 200 OK буцааж байна

**Орчин:** Уншлагын жагсаалт v2.0, Node.js v24.19.0, Ubuntu Linux, 2026-10-22

**Урьдчилсан нөхцөл:** `node app.js` командаар апп ажиллаж, `localhost:3000` хаяг руу хүсэлт илгээх боломжтой байна.

## Дахин гаргах алхам

1. Аппыг `node app.js` командаар ажиллуулна.
2. Ubuntu терминал нээнэ.
3. Дараах командыг ажиллуулна.

```bash
mkdir -p evidence

curl -i -X POST http://localhost:3000/api/books \
  -H "Content-Type: application/json" \
  -d 'буруу оролт' 2>&1 | tee evidence/bug-08-curl.txt
```

4. HTTP статус болон хариуны биетийг шалгана.

## Хүлээгдэж байсан үр дүн

Буруу JSON форматтай POST хүсэлтэд сервер `400 Bad Request` статус буцааж, хүсэлт амжилтгүй болсныг илэрхийлсэн алдааны хариу өгөх ёстой.

## Бодит үр дүн

Сервер `200 OK` статус буцааж, дараах хариуны биетийг илгээсэн:

```json
{"result":"OK"}
```

Ингэснээр буруу JSON форматтай хүсэлт амжилттай боловсруулагдсан мэт харагдаж байна. Хүлээгдэж байсан `400 Bad Request` статусын оронд `200 OK` буцаасан нь API-ийн алдаа боловсруулах үйлдэл буруу байгааг харуулж байна.

**Ноцтой байдал:** Major — API буруу форматтай хүсэлтийг зөв ялгаж, алдааны статус буцаахгүй байна.

**Нотолгоо:** `evidence/bug-08-curl.txt`

**Олдсон аялал:** Saboteur — API руу буруу форматтай JSON оролт илгээж, алдааны боловсруулалтыг шалгах.
