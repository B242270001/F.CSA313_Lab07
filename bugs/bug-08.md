# BUG-08: Буруу JSON биеттэй POST хүсэлтэд 400 биш 201 Created буцааж байна

**Орчин:** Уншлагын жагсаалт v2.0, Node.js v24.19.0, Ubuntu Linux, 2026-10-17

**Урьдчилсан нөхцөл:** `node app.js` командаар апп ажиллаж, `localhost:3000` хаяг руу хүсэлт илгээх боломжтой байна.

## Дахин гаргах алхам

1. Аппыг ажиллуулна.
2. Ubuntu терминал нээнэ.
3. Дараах командыг ажиллуулна.

```bash
mkdir -p evidence

curl -i -X POST http://localhost:3000/api/books \
  -H "Content-Type: application/json" \
  -d 'буруу оролт' 2>&1 | tee evidence/bug-08-curl.txt
```

4. HTTP статус болон хариуны биетийг шалгана.

## Хүлээгдэж байсан үр дүн

Буруу JSON биеттэй POST хүсэлтэд `400 Bad Request` статус буцаах ёстой.

## Бодит үр дүн

Сервер `201 Created` статус буцааж, дараах хариу ирсэн:

```json
{"result":"OK","id":4}
```

Буруу JSON биеттэй хүсэлт амжилттай боловсруулагдсан мэт хариу ирсэн.

**Ноцтой байдал:** Major — API буруу хүсэлтийг зөв ялган боловсруулахгүй байна.

**Нотолгоо:** `evidence/bug-08-curl.txt`

**Олдсон аялал:** Saboteur — API руу буруу форматтай оролт илгээх.
